# Emergency-Alert-and-Complaint-Management-System
Android app for emergrncy SOS alerts and complaint management using Firebase


## 📱 Overview

The **Emergency Alert and Complaint Management System** is an Android application developed as an MCA final-year project. It enables citizens to send emergency SOS alerts, share their live location, register complaints, and receive real-time updates. The system also provides dedicated interfaces for police and administrators to manage emergencies and complaints efficiently.

## ✨ Features

### Citizen Module

* User Registration and Login
* Emergency SOS Alert
* Live Location Sharing
* Add and Manage Guardians
* Register Complaints
* Track Complaint Status
* Push Notifications
* Profile Management

### Police Module

* Secure Login
* Receive SOS Alerts
* View Citizen Location
* Manage Complaints
* Update Complaint Status
* Notification Support

### Admin Module

* Manage Users
* Manage Police Accounts
* Monitor SOS Alerts
* Monitor Complaints
* Generate Reports
* System Monitoring

## 🛠️ Technologies Used

## 🚀 How to Run

1. Clone this repository.
2. Open the project in Android Studio.
3. Connect your Firebase project.
4. Add your `google-services.json` file.
5. Sync Gradle.
6. Build and run the application on an Android device or emulator.
